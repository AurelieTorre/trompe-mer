# 🎨 Site de présentation - Artiste peintre

Ce projet est une application web **Single Page Application (SPA)** développée avec **React**, destinée à présenter les œuvres et l'univers artistique d'une peintre contemporaine.

## 🌟 Fonctionnalités

- Galerie d’œuvres (images hébergées localement)
- Présentation de l’artiste
- Site responsive
- Navigation fluide entre les pages (SPA sans backend)

## 🛠️ Technologies utilisées

- React
- React Router
- CSS (styles personnalisés via `App.css` et `index.css`)

## 📁 Structure du projet
```text
public/
├── favicon.ico
├── index.html
src/
├── assets/
├── components/
├── pages/
├── App.jsx
├── App.css
├── index.js
└── index.css
.env # Contenant la clé d'API pour l'horaire des marées
```

## ▶️ Démarrer le projet en local

```bash
npm install
npm start
```

Le site sera accessible à l'adresse : http://localhost:3000
